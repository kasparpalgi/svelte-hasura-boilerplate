**The fix** — when a run exits with a **clean tree** but the file is still `-TODO`, the
runner now finishes the bookkeeping the agent skipped: appends a runner note (only if the
agent wrote no Results), renames to `-DONE`, commits, pushes, and runs `closeLoop` so the
card moves to Review and reports **✔**. A **dirty** finish is unchanged — it still parks the
uncommitted work in a stash and warns, since leftover work can't be guessed.

**How to proceed (the advice you asked for):**

- **You don't trigger the next task — the daemon does.** It records a run as finished the
  moment the agent goes idle (rename, push, card move all happen *before* the pane is left
  open). On the next poll (`pollSeconds`) it picks the next `-TODO.md` and `reap()` closes
  your left-open `task-*` pane. A left-open pane never blocks the queue.
- **`/exit` does nothing for the queue.** It only ends Claude inside that one pane; the
  runner is a separate launchd daemon that doesn't watch the pane, so exiting neither starts
  nor speeds up the next task. When you're done with follow-ups, just leave it — the next run
  reaps the tab. (That's why `/exit` "didn't start the next session".)
- **Going forward**, a run that looks done in the pane but whose card didn't move is now
  self-healed on a clean tree, so it no longer needs a manual rename.
